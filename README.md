# JARVIS — Desktop Notes

This folder is a staging location for JARVIS work and backups.

## Working copy

`JARVIS/` — cloned project repository (with `.git`).

## Copies

`jarvis/` — a copy of the `JARVIS/` project tree. Created as a convenience copy for review and for preparing moves between machines. It is **not** a separate repo in this location.

## Archives

`*.tar.gz` files are full or partial backups of the project tree as of their timestamps. Treat them as point-in-time snapshots.

## Diagnostics and reviews

`jarvis-*.txt` files are exported diagnostics, source reviews and audit transcripts produced during repair sessions.

## Notes

- Some filenames here were created with unusual casing or duplicates (for example `JARVIS Island.desktop` and `jarvis-island.jarvis-island`). Those were removed when harmless, but if anything important is missing, check the backups and the `JARVIS/` repo.
- The canonical project history lives in `JARVIS/.git`.
